# POLUTO Website

- POLUTO is an evolving physical AI work companion project exploring awareness
  of asynchronous AI activity and moments requiring human input.
- The website introduces the project and may grow into a development journal
  and archive of encounters. Public website text is English by default.
- Keep the site simple, static, maintainable, responsive, and accessible.
  Minimize dependencies and add features or abstractions only when needed.
- Use only supplied or approved project materials. Preserve media originals;
  create separate web-optimized copies when necessary.
- Never invent capabilities, research results, publications, authors,
  affiliations, acceptance, awards, or visitor messages.
- Clearly distinguish confirmed facts, current implementation, proposed
  interactions, and placeholders. Do not present placeholders as real material
  or add empty media interfaces for unavailable content.
- Inspect Git status and existing instructions before editing. Preserve user
  changes and existing files. Do not use destructive Git commands or force-push.
- Do not commit, push, deploy, or change remotes, branches, or GitHub settings
  without explicit user authorization. Confirm major structural changes first.
- Do not display personal GitHub usernames, profile links, or account widgets.
  Never commit secrets, credentials, confidential research, or other people's
  images and messages without permission. Public repository files and Git
  author metadata may be visible even when absent from the website.
- Keep purpose, local preview, and deployment instructions in README.md.
  Avoid unnecessary documentation; verify changes and report any limitations.
